## Why

Visara sits on React Native 0.81.4 (Aug 2025) — five releases behind 0.86.0 — and the gap is now load-bearing: Reanimated 3.19 does not support RN 0.84+, Reanimated 4.5.1 peer-requires RN 0.83–0.86, and the planned page-navigation rebuild (pager-view 8 + gesture-handler 3) peer-requires the new stack. The 11-agent research pass (2026-07-03, results in session scratchpad `research/*.json`) confirmed the platform jump and the Software Mansion animation stack are **inseparable** and must land as one atomic change. Every dependent improvement (Nitro infra majors, image-pipeline replacement, UI rebuild) is blocked behind this change.

## What Changes

- **BREAKING (platform): react-native 0.81.4 → 0.86.0, react 19.1.0 → 19.2.3**, `@react-native/babel-preset` + `@react-native/metro-config` → 0.86.0, CLI trio → 20.1.0 (`cli-platform-android` moves to devDependencies; **add missing `cli-platform-ios`**). Crosses: 0.82 (New-Arch-only — we already are), 0.84 (Hermes V1 default, Node ≥22.11, legacy arch stripped from iOS builds, prebuilt RNCore xcframework default), 0.85 (Gradle 9.3.1, `StyleSheet.absoluteFillObject` removed, jest preset extraction), 0.86 (edge-to-edge correctness fixes).
- **BREAKING (animation stack, lockstep pins):** reanimated 3.19.3 → **4.5.1** + new mandatory `react-native-worklets@0.10.1`; babel plugin renamed `react-native-reanimated/plugin` → `react-native-worklets/plugin` (stays last); gesture-handler 2.28 → **3.0.2**; pager-view 6.9.1 → **8.0.2** (iOS SwiftUI rewrite); reanimated-dnd 1.1.0 → **2.0.0** (the reanimated-4 build; only AlbumList.tsx). - **Template diff application with local-mod preservation** (one true collision): port `MainApplication.kt` from `DefaultReactNativeHost` to lazy `getDefaultReactHost(...)` **keeping `MediaObserverPackage()` + `ThermalObserverPackage()`**; gradle wrapper 8.14.3 → 9.3.1 (all four wrapper files); pbxproj "Bundle React Native code and images" quoting fix + add `SUPPORTED_PLATFORMS`/`TARGETED_DEVICE_FAMILY`; `...StyleSheet.absoluteFillObject` → `...StyleSheet.absoluteFill` in exactly `src/components/atoms/Thumbnail.tsx:90` and `src/components/organisms/PhotoViewerModal.tsx:220`; add `CADisableMinimumFrameDurationOnPhone=true` (ProMotion 120Hz). **Preserved untouched:** iOS 26.0 floor, `platform :ios '26.0'`, fmt-consteval Podfile patch, simdjson pod, minSdk/compileSdk 36, arm64-v8a-only abiFilters, `com.visara.app` namespace/signing, visara_launcher icons, vector-icons fonts.gradle, metro.config.js, and `index.js` executorch-init-before-registration order.
- **Minors riding along** (screens peer-blocks earlier install): react-native-screens 4.25.2, safe-area-context 5.8.0, @react-navigation native 7.3.6 / stack 7.10.8 / bottom-tabs 7.18.6, device-info 15.0.2, @shopify/flash-list 2.3.2, background-actions ^4.1.0 (in range).
- **Toolchain aligned to the 0.86 template, not latest:** KEEP TypeScript 5.9.3 and Babel 7 (bump to ^7.29.x) — **TS 6.0 and Babel 8 explicitly rejected** (template pins ^5.8.3 / ^7.25); jest 30.2.0 → template ^29.6.3 with new `jest.config.js` (`@react-native/jest-preset@0.86.0`) so `npm test` stops erroring on an empty suite; @testing-library/react-native → 14.0.1 + its new `test-renderer` peer; **remove stale `@types/react-native@0.72.8` and `metro-react-native-babel-preset`** (conflict with RN-bundled types/preset); `engines.node` → `>= 22.11.0`.

- **PULLED FORWARD (discovered during apply): react-native-mmkv 3.3.3 → 4.3.2 + new `react-native-nitro-modules@0.36.1` substrate.** mmkv 3.3.3 segfaults on iOS under RN 0.86 (`MMKV::set(bool)` → `KERN_INVALID_ADDRESS at 0x0`, crash report 2026-07-03; no 3.x fix line exists) — exactly the researched risk; research had already recommended 4.3.2 ride the RN move. Blast radius: `src/services/storage/mmkv.ts` (`createMMKV`, `remove`) + one direct `storage.delete` in EncryptionService. `id`/`encryptionKey` byte-identical (on-disk AES-128 data continuity verified by research). Change B shrinks to quick-crypto + vision-camera.
- **`overrides` for react-native-fast-image** (peer `react ^17||^18` hard-blocks re-resolution under react 19.2.3) — surgical, self-documenting, removed when the image-pipeline replacement change deletes fast-image.
- **HARD GATE (checked first):** `react-native-executorch@0.9.2` stays byte-for-byte pinned and MUST build and `initExecutorch` cleanly under RN 0.86 + Hermes V1 — its published compat table stops at 0.85, so this is the single go/no-go for the whole change.

## Impact

- **Dependencies:** ~20 packages bumped, 2 removed, 3 added (`react-native-worklets`, `@react-native-community/cli-platform-ios`, `@react-native/jest-preset`); package-lock regenerated wholesale (verify no mixed 0.81/0.86 `@react-native/*` scoped packages via `npm ls`).
- **Android:** `gradle/wrapper/*` (4 files, Gradle 9.3.1 — watch third-party gradle scripts: vector-icons fonts.gradle, background-actions, notifee, watermelondb, executorch under Gradle 9's removed APIs), `MainApplication.kt` (reactHost port). `android/build.gradle`, `settings.gradle`, `MainActivity.kt`, `AndroidManifest.xml`, launcher assets: untouched by template.
- **iOS:** `project.pbxproj` (shellScript quoting, SUPPORTED_PLATFORMS, TARGETED_DEVICE_FAMILY), `Info.plist` (+ProMotion key; orientations kept), full `pod install` regeneration against RN 0.86 prebuilt-core pipeline (fmt patch expected to no-op safely; keep `RCT_USE_PREBUILT_RNCORE=0` as escape hatch).
- **JS:** 2-file absoluteFillObject fix; babel plugin rename; zero other mandatory source changes (research-verified).
- **Behavioral risk accepted:** reanimated 4 spring physics differ (energyThreshold model, perceptual duration) across 8 files using `withSpring` — functional QA required; `Reanimated3DefaultSpringConfig` is the escape hatch if feel regressions matter.
- **Runtime risk to smoke-test:** Hermes V1 under the JSI-heavy stack (WatermelonDB+SQLCipher, MMKV 3, quick-crypto 0.7, executorch); fast-image 8.6.3 on the interop layer (replacement is a later change); edge-to-edge metric shifts on Android 16.
- **Out of scope:** mmkv 4 / quick-crypto 1.x / vision-camera 5 (next change: Nitro substrate), fast-image + vector-icons replacement, page-navigation rebuild, notifee-is-archived migration (flagged for backlog).
