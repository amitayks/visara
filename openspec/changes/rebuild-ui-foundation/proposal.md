# Rebuild UI Foundation

## Why

Visara's UI layer has decayed into a liability: five reducer contexts where roughly half of all state shape is dead, a provider pyramid that re-renders the full visual tree on any settings change, an entire media-file array mirrored into React context on every DB write (two full re-renders per processed photo during drains), three split-brain stores (grid zoom never persists, battery/night MMKV keys have two writers with clashing types causing silent toggle reverts, duplicated search-mode flags), an N+1 per-keystroke search, a mock-data Albums screen, and react-native-paper installed to render a single icon wrapper. Incremental repair costs more than a rebuild — and July-2026 tooling (Unistyles 3's zero-re-render C++ theming, Zustand 5, React Navigation 7 static API + native-stack, TrueSheet) is verified compatible with this exact repo (RN 0.86 New Architecture, React 19.2, nitro-modules 0.36.1 already installed).

## What Changes

- **BREAKING (internal): delete the entire UI layer** — `src/contexts/`, `src/navigation/`, `src/screens/`, `src/components/`, `src/theme/` — and rebuild from scratch. `src/services/`, `src/models/`, `src/native-modules/` (codegen inputs), `src/shared-types/`, `src/assets/` stay.
- **New design system ("Visara DS")**: design tokens + dark-first theming on react-native-unistyles 3 (C++ Fabric, zero-re-render theme switching), ~15 owned primitives on RN primitives + Reanimated 4 + Gesture Handler 3 declarative API, icons rendered directly from `@react-native-vector-icons/material-design-icons`, native bottom sheets via TrueSheet, toasts via sonner-native. react-native-paper removed.
- **New state architecture**: Zustand 5 domain stores (settings, navigation/UI, selection, search, processing, model) replace the five contexts; WatermelonDB remains the reactive source of truth consumed via throttled observable subscriptions at the screen level (never mirrored into global stores); MMKV persistence with single-owner, single-type keys plus migration for the legacy string-typed values; high-frequency pipeline progress feeds Reanimated SharedValues with zero React re-renders.
- **New navigation shell**: React Navigation 7 static API with native-stack (JS stack removed); root tree = Onboarding gate → Shell (pager: Gallery ↔ Albums + morphing bottom bar) with PhotoViewer (transparent modal), Settings (pushed screen, replacing the overlay drawer), and dev-only POC screens; centralized Android back handling; all page-navigation-core gesture invariants preserved (origin-judged 50px edge zones, velocity-500/distance-100 thresholds, search-exits-on-swipe, document-persists).
- **Rebuilt experiences with the known bugs fixed**: gallery grid (no FlashList remount on pinch-zoom, persisted zoom, O(n) rendering), photo viewer (correct metadata after swipe — info/share/delete acted on the wrong photo), inline search (debounced, stale-response-guarded, batch-hydrated, label-tap activates search mode), Albums rebuilt on the real `AlbumRepository` (smart albums from AI labels, custom albums, drag-reorder actually wired and persisted), Settings screen with implemented data actions (clear cache, delete all data — currently console.log stubs), onboarding with a working Skip button and a real permission-denied state.
- **Services wiring**: the null-rendering OrchestratorBridge component becomes a headless TypeScript bootstrap module preserving the exact boot order and event contract; a thin services facade adds `searchMedia` (batched hydration), `removeMedia` (full cleanup incl. indexes and queue), `ensureSearchIndex` (index lifecycle out of screens), and fixes the battery/night settings ownership.
- **Dependency changes**: add `react-native-unistyles@3.2.5`, `zustand@5.0.14`, `@react-navigation/native-stack`, `@lodev09/react-native-true-sheet`, `sonner-native`; remove `react-native-paper`, `@react-navigation/stack`, `@react-navigation/bottom-tabs`; bump `react-native-pager-view` 8.0.2 → 8.0.3. Reanimated 4.5.1 ↔ worklets 0.10.1 exact lockstep, GH 3.0.2, FlashList 2.3.2, expo-image 57 unchanged.
- **Test enablement**: Jest configured for the real dependency set (transformIgnorePatterns + mocks for reanimated/GH/expo/@nozbe) with tests for store logic, gesture math, and search behavior — the repo currently has zero tests.

## Capabilities

### New Capabilities
- `ui-design-system`: Unistyles token system (colors/spacing/radii/typography/motion), dark-first adaptive theming incl. status bar, the owned primitive set (Text, Button, Icon, Sheet, Menu, Dialog, Chip, SegmentedControl, Toast, Skeleton, EmptyState, SelectionBar…), accessibility baseline.
- `ui-state-management`: Zustand store topology, state taxonomy rules (DB-cache vs UI vs persisted vs derived), MMKV key ownership/types/migration, DB-observable consumption rules (screen-level, throttled, never store-mirrored), SharedValue path for high-frequency progress.
- `app-navigation-shell`: root native-stack static tree with onboarding gate, pager shell hosting Gallery/Albums, morphing bottom bar (stagger choreography, keyboard avoidance, pointer-events safety), centralized back handling, screen inventory incl. dev-only gating.
- `gallery-experience`: date-sectioned grid with 3/4/11 pinch zoom (persisted), multi-select, document filter, photo viewer gestures with correct per-photo metadata, info sheet, photo actions (share/copy/delete with full cleanup).
- `search-experience`: inline search mode UX — debounced hybrid search via facade, stale-response guard, batch hydration, results replacing the grid, label-tap entry, empty/error states.
- `albums-experience`: smart albums derived from AI labels, custom album CRUD on AlbumRepository, drag-reorder (wired + persisted), album detail grid.
- `settings-experience`: Settings as a pushed native-stack screen — appearance, processing controls (battery saver/night processing), AI model section, data management (implemented cache clear + full data deletion), about/legal.
- `onboarding-experience`: onboarding flow with working skip, real permission request/denied states, privacy copy contract, non-blocking model step, completion semantics that boot the pipeline.
- `services-ui-facade`: the UI-facing services surface — `searchMedia`, `removeMedia`, `ensureSearchIndex`, subscription normalization (emit-on-subscribe), settings-key ownership fix, boot-order contract.

### Modified Capabilities
- `page-navigation-core`: page-state authority moves from `NavigationContext.currentPage` to the navigation store; right-edge swipe on Albums now opens the Settings screen (was: overlay drawer); all gesture-origin/threshold/mode-semantics requirements re-anchored to the new shell, behavior preserved.
- `orchestrator-gallery-bridge`: the React bridge component requirement becomes a headless bootstrap module + store wiring; event-to-state mapping contract preserved; gallery population re-anchored from GalleryContext dispatch to throttled screen-level observable subscription; permission-denied becomes a surfaced UI state instead of a silent boot abort.
- `reanimated-4-animation-stack`: protected-surfaces list updated for the rebuilt UI (sheets move to TrueSheet native presentation; morph/pager/viewer/drag surfaces remain Reanimated); library pins unchanged.
- `onboarding-model-step`: requirements decoupled from deleted component names (`OnboardingScreen` screens array / `OnboardingTemplate`); non-blocking and privacy-copy contracts preserved verbatim.
- `ai-model-settings`: section re-anchored from `SettingsDrawer` pattern to the Settings screen; enabled-state must come from the delivery service subscription (fixing the local-snapshot drift); all lifecycle/progress/disk requirements preserved.
- `scoped-vector-icons`: icon requirement decoupled from react-native-paper (removed dependency) — glyphs render through the design system's own Icon primitive directly over the scoped MaterialDesignIcons package; single-font bundle rules unchanged.

## Impact

- **Deleted**: `src/contexts/*` (5 files), `src/navigation/*` (5), `src/screens/*` (all), `src/components/*` (all 23), `src/theme/*` — ~6,000 LOC. Dead code (SettingsScreen, SearchBar, BottomNavContainer, ProcessingIndicator, unused nav config) is not rebuilt.
- **Created**: `src/ui/` (design system), `src/state/` (stores), `src/app/` (shell, bootstrap, navigation), `src/features/` (gallery, albums, search, settings, onboarding, viewer), facade module in `src/services/`.
- **Touched but preserved**: `index.js` entry contract (initExecutorch before registerComponent), `src/native-modules/*.ts` (codegen inputs — must not be deleted), babel/tsconfig path aliases (updated in BOTH files), Podfile (pod install for unistyles/TrueSheet), Jest config.
- **Services**: additive facade only + settings-key ownership fix in `BackgroundTaskService`; orchestrator/DB/ML pipeline internals untouched; MMKV encryption key untouched.
- **Dependencies**: +5 / −3 as listed above; all verified against RN 0.86 / React 19.2 / New Arch / nitro 0.36.1 / static pods / 16KB-page Android images.
- **Risk concentrations**: Unistyles-on-0.86 day-one spike (fallback: typed StyleSheet tokens with the same token shape); pager+RNGH gesture interop (mitigated by porting the debugged HorizontalPageContainer worklet logic verbatim); iOS TurboModule + expo-modules coexistence (no native module changes made); reanimated-dnd Sortable scroll-container constraint on the rebuilt Albums page.
- **Out of scope** (follow-up changes): thumbnail generation pipeline (grid will prefer `thumbnailUri` when present), notifee replacement, DB encryption adoption, MODEL_ENABLED/embedding-gate decoupling, search-index serialization batching, video support.
