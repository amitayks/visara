# Visara

A smart document scanner that automatically extracts and organizes text from your photos.

## Features

**Automatic Document Detection**
- Scans your photo gallery for documents, receipts, and text-based images
- Background processing with real-time progress tracking
- Smart filtering to identify document-like content

**Advanced OCR Processing**
- Multiple OCR engines (MLKit, Tesseract, VisionCamera) for maximum accuracy
- Confidence-based engine selection for optimal text extraction
- Support for multiple languages and document types

**Intelligent Organization**
- Automatic document type classification (receipts, invoices, notes, etc.)
- Keyword extraction for better searchability
- Metadata extraction including dates, amounts, and vendors

**Powerful Search**
- Full-text search across all your documents
- Semantic search with keyword matching
- Filter by document type, date, or content

**Smart Performance**
- Memory-optimized OCR processing
- Efficient local database storage with WatermelonDB
- Battery-aware scanning options

**Modern Experience**
- Clean, intuitive interface
- Dark and light theme support
- Smooth animations and responsive design
- Real-time document updates

## Built With

React Native • TypeScript • WatermelonDB • Multiple OCR Engines
