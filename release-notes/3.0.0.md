# Visara 3.0.0 — On-device AI

> **Status:** Prepared. The version bump, reconciliation, and the floor/impact
> section below are final. The **on-device-AI "what's new" copy, supported-device
> claims, and any minimum-RAM guidance are POC-dependent placeholders** — they are
> finalized only after the **#4/#6 on-device Gemma inference POC records GO**, and
> matched to the POC's real output shape, latency, and quality. **The POC (#4) is
> the pre-ship GO gate: NO-GO halts this AI release.**

## Headline

Visara moves its entire understanding pipeline **on-device**. The cloud/ML-Kit
labeling stack is retired and replaced by an on-device **Gemma-4 multimodal**
enrichment engine running on the **ExecuTorch** runtime, with semantic (vector)
search over your library. Everything runs locally — your photos never leave your
phone.

## What's new

> The AI-capability bullets below are **provisional / POC-dependent** and will be
> finalized against the #4/#6 POC result before publication.

- **On-device Gemma-4 multimodal enrichment (Tier-1).** _(POC-dependent copy)_
  A local multimodal model generates rich descriptions/understanding of your
  photos for search and organization — no network, no upload.
- **ExecuTorch runtime.** The on-device inference is powered by ExecuTorch
  (`react-native-executorch`), replacing the previous ML-Kit path.
- **GoogleMLKit retired.** Baseline OCR/classification (Tier-0) now runs on
  ExecuTorch, with an **Apple Vision** fallback on iOS. There is no ML-Kit
  dependency anymore.
- **Semantic / vector search.** Search now matches meaning, not just exact text
  — find photos by what's in them, alongside the existing full-text/fuzzy search.
- **Capability + thermal gating.** The app checks device capability and thermal
  state before running heavy inference, so on-device AI only engages when the
  device can sustain it, and backs off to protect responsiveness and battery.
- **Model delivery.** The AI model is delivered/downloaded on first run rather
  than bundled, keeping the base install smaller. _(Expect a multi-GB first-run
  download — see Requirements and Known limitations.)_
- **Library reprocessing.** Existing libraries are (re)processed through the new
  engine so older photos gain the new understanding/search capabilities.
- **arm64 iOS Simulator unblocked.** Development/QA builds now run on the arm64
  iOS/iPadOS 26 Simulator (previously blocked).

## User impact / requirements

**This is a major release with a raised support floor. Some older devices will
no longer receive updates.**

- **iOS: requires iOS 26.0 or later.** Devices below iOS 26.0 will not receive
  this update (App Store shows "Requires iOS 26.0 or later"; TestFlight excludes
  sub-26.0 devices).
- **Android: requires Android 16 (API level 36 / `minSdk 36`) or later**, on
  **`arm64-v8a`** devices only. 32-bit and `x86`-only devices are no longer
  supported and will not receive this update.
- **First-run model download.** On first launch the app downloads the on-device
  AI model — expect a **multi-GB** download over Wi‑Fi and some setup time
  before AI features are ready.
- **On-device processing.** All AI enrichment/OCR/search indexing runs locally;
  nothing is uploaded.

Devices on an older OS, or that are 32-bit / `x86`-only, remain on the previous
version and stop receiving updates. This narrowing of the support matrix is a
deliberate, disclosed part of the on-device-AI move.

## Known limitations

- **First-run cost.** The multi-GB model download and initial library
  (re)processing take time and storage; enrichment runs progressively in the
  background under capability/thermal gating.
- **Device class for inference.** _(POC-dependent)_ On-device inference targets
  higher-end devices (e.g. iPad Pro / Android flagship). **iPhone is currently
  excluded as an on-device-inference device**, pending the #4/#6 POC result; any
  minimum-RAM / device-class guidance is finalized from that POC.
- **Thermal back-off.** Under sustained load or high temperature, enrichment
  pauses and resumes later, so full-library processing may span multiple
  sessions.
- **Model output quality/latency** _(POC-dependent)_ are finalized against the
  POC before the AI copy above is published.
